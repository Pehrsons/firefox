Description

The specification says that when the queue is full the oldest frame is removed, so "for the particular case of a queue with a maximum size of 1, if there is a queued frame, it will always be the most recent one". These tests stall the reader and check that what comes back afterwards is a fresh frame rather than one buffered when the stall began, both while the worker's event loop stays free and while it is blocked, which are different paths into the queue. They are here rather than upstream because they need a track transferred to a worker, which only Gecko supports so far.
